# Orbit Rides

![Orbit Rides](https://orbit-rides.vercel.app/images/social-media-image.jpg)

## Overview
Orbit Rides is a car rental platform designed to provide a seamless experience for both administrators and customers. It features an intuitive UI, robust authentication, and dynamic pages for managing cars, bookings, and more.

## Features
- Dynamic admin dashboard for managing bookings, cars, and more.
- Customer dashboard with car browsing and booking capabilities.
- Secure authentication system powered by Supabase.
- Responsive design optimized for both desktop and mobile devices.
- Modern UI and intuitive workflows.

## Technologies Used
- **Next.js 15**
- **Supabase**
- **Stripe**
- **DaisyUI**
- **Cloudflare Turnstile**
- **FilePond**
- **Framer Motion**
- **Leaflet**
- **Next Themes**
